🚀 БЫСТРЫЙ СТАРТ - 3 минуты
================================

Форма готова! Осталось 3 простых шага:

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ШАГ 1: Получи бесплатный ключ
──────────────────────────────

1. Открой: https://web3forms.com
2. Введи свой email
3. Проверь почту
4. Скопируй Access Key из письма

   Выглядит так:
   ✓ a1b2c3d4-e5f6-7890-abcd-ef1234567890

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ШАГ 2: Вставь ключ в код
─────────────────────────

1. Открой: script.js
2. Найди строку 920:
   formData.append('access_key', 'YOUR_ACCESS_KEY_HERE');
   
3. Замени YOUR_ACCESS_KEY_HERE на свой ключ:
   formData.append('access_key', 'a1b2c3d4-e5f6-7890-abcd-ef1234567890');
   
4. Сохрани файл (Ctrl+S)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ШАГ 3: Протестируй
──────────────────

1. Открой index.html в браузере
2. Нажми "Contacts" в меню
3. Заполни форму тестовыми данными
4. Нажми "Send"
5. Проверь свой email 📧

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ ВСЁ! Теперь все заявки приходят на email!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   • Причина обращения
   • Дополнительные детали (если выбрано "Other")

❓ Проблемы?

1. Не приходит письмо?
   → Проверь папку "Спам"
   → Проверь, правильно ли вставил ключ

2. Ошибка "Submission failed"?
   → Проверь интернет соединение
   → Убедись, что ключ активен (письмо от Web3Forms)

3. Хочешь другой сервис?
   → Смотри EMAIL_SETUP.md (EmailJS, Formspree)
